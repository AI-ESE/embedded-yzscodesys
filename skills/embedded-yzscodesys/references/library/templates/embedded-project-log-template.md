# 工程Log记录模板

在工程根目录创建Log，分别维护以下两个Markdown文件。每次新的记录追加到对应文件最后，与上一条空行分隔；占位字段不是已完成记录。

## Log/版本记录.md

```text
版本号：
修改日期：
修改涉及文件：
修改内容或者功能：
```

涉及多个文件逐行列出工程相对路径；内容说明具体行为变化、原因及必要的验证/待处理项。修改前结合历史记录和当前代码分析，修改后登记实际结果。

## Log/提示词记录.md

```text
提示词时间：
精简提示词内容：
最终改善输出：
```

每次用户提问保留精简需求、约束、实际改善/分析结论和关联产物位置。没有代码改动时写清实际分析输出或待处理事项。检索按模块、功能、引脚、问题关键词、文件路径和版本关联。

细则见[LG01–LG06](../rules/embedded-log-rules.md)。
