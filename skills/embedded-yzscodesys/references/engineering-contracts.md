# 按具体工程补齐的技术契约

这些是落实已有规则的分析项目，不新增固定芯片参数或统一硬件预算。按资料和工具链填写，纳入方案/复盘证据。

| 领域 | 核对契约 |
| --- | --- |
| 平台 | 完整型号/封装、内核、CHAR_BIT、精确类型、指针/ABI、SDK/勘误、启动及链接、构建组合 |
| 生命周期 | 时钟/电源/复位顺序、模块依赖、重复调用、部分失败、关闭/恢复、数据就绪发布 |
| 裸机 | 时基、分时周期/预算、非阻塞状态机、事件积压、计时回绕、超期、控制快路径 |
| FreeRTOS | 匹配移植、优先级、栈单位/预算、堆策略、ISR API/优先级、同步、队列满/超时与健康监测 |
| 并发/DMA | 所有者、读改写、快照、缓冲区持有期、锁顺序、临界区恢复、适用缓存一致性、位域共享单元竞争 |
| 数值/内存 | 符号、整数提升、移位/溢出、定点标度、指针/数组边界、堆栈、段放置、对齐和余量 |
| 结构体 | 模块_分类；配置/状态/上下文/请求响应/诊断/标志分开；公共与私有布局、生命周期、唯一修改者 |
| 故障保护 | 可信输入、业务许可、保护/锁存、输出默认态/故障态、恢复、看门狗喂狗依据、复位/异常现场 |
| 通信存储 | octet/存储单元、端序、长度/单位、帧校验、超时/重试/重复命令、提交确认、版本/掉电恢复与磨损 |
| 发布 | 实际配置/优化/ABI、SDK告警基线、产物与输入绑定、MAP/反汇编、功能组合、目标构建与硬件测量分开 |
| 屏幕UI（适用时） | 屏幕/驱动、Flash/RAM已有占用及余量、字库/Logo/页面资产与缓存/帧缓冲；同页HTML与程序U1/U2/U3三轮均≥92%，关键功能及资源满足再转下一页 |

依据[结构体规则](library/rules/embedded-struct-rules.md)与[类型/宏规则](library/rules/embedded-type-macro-rules.md)落实位域、联合体和类型。示例头不是任意芯片的完整驱动；无精确8位类型时明确端口/协议适配。

固定功能与预算来自用户确认；输出极性和限值从原理图、规格书和产品需求核对，不把示意图推导成实测。
